Personal Google Drive integration

lecture-harness-rclone

A personal desktop OAuth integration that connects rclone to Google Drive for the account owner's lecture-harness workflow. It reads existing course materials and uploads completed lecture notes and associated images to the owner's Drive.

What this integration does

  • Lists and downloads existing files and folders selected by the owner.
  • Uploads generated lecture notes, PDFs, and image assets.
  • Manages files in designated output folders and removes temporary verification files when requested.

The integration requests the Google Drive scope https://www.googleapis.com/auth/drive because the workflow needs existing materials uploaded outside this app. The narrower drive.file scope cannot provide that access.

Personal use

This integration is operated by Xuxiang for personal use. It is not a public file storage service. Google Cloud project ownership is separate from the Google Drive account selected during consent. The integration does not transfer ownership or automatically share the owner's course materials.

Read the privacy policy and terms of use before granting access. This website does not request or collect your Google password or OAuth tokens.
